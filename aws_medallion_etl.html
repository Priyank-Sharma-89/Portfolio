Project Overview

Cloud ETL Pipeline with Medallion Architecture.

Just like my Azure's first project, I have implemented & showcased the same medallion architecture setup in AWS ecosystem.

Considering all the learning i gathered in Azure, I thought this project will be similar to implement on conceptual level since its just the change of cloud and change of services, basic core concepts remain same, however, to my surprise, in AWS, willingly or unwillingly, I learnt much more than core concepts and much more than whatever I learnt in Azure.

AWS challenged me in many of its quirky ways, and gave me opportunity to learn way beyond than just the ETL pipeline flow.

So, the core learning, features and explanations remain the same as Azure Medallion ETL pipeline (you may refer it to see what I am talking about), but whatever additional I learnt, I will list it out here, also, do make sure to checkout the GIT repo of this project, as I have shown my entire progress, and not just learning, whatever challenges I faced, in detailed visuals with the help of screenshots.

Key Learnings:

  • AWS Console & UI
  • Selecting the right Region globally for all services, or how services in console are tied to the selected/default non selected region.
  • Understanding of Data Catalog, Database/Table creation and Crawler. How they function in comparison to LinkedServices and Dataset in Azure.
  • Auto table creation using Crawler.
  • IAM role for services, configuring proper full read/write permissions in role.
  • Athena to view or query Data. Understanding that Athena does not hold data, data always remain in S3.
  • Pipeline creation & Transformation in Glue.
  • Parquet data format.
  • Why the Glue ETL job took 1 min 24 sec, despite being data so small in kbs.
  • Why I see final Gold layer aggregated output in 5 parts/5 different output files.
  • AWS Cost management, which services actually generate cost under which circumstances.

Debug & fix issues related to:

  • Proper full read/write permission not attached to IAM role.
  • Query syntax differences in Athena Presto SQL engine.
  • Use SQL Query Transform in Glue.
  • Forgot to add 'Data Target' in ETL and ran the job.
  • Modular code for multi-step data cleaning & transformation.
